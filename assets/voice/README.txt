Put recorded voice files here (mp3, wav, m4a or ogg) to replace the phone's robot voice.

Name each file after the exact phrase the app says, in lowercase, with spaces and
punctuation turned into "_". Examples:
  "A for Apple"          -> a_for_apple.mp3
  "B says buh, buh"      -> b_says_buh_buh.mp3
  "Cow"                  -> cow.mp3
  "Moo! Moo!"            -> moo_moo.mp3
  "Well done!"           -> well_done.mp3
  "अ से अनार"             -> अ_से_अनार.mp3
Phrases without a recording keep using the phone voice. Rebuild the APK after adding files.
